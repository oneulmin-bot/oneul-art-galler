# (사)오늘은 아트 갤러리 — 배포·운영 안내

| `assets/pages/*.js` | 페이지별 로직 |
| `../apps-script/Code.gs` | 시트 ↔ JSON 변환, 방명록/관리자 기능 Apps Script 코드 |

## 1. Apps Script 연결
1. script.google.com 에서 **새 프로젝트**를 만들어 `apps-script/Code.gs` 전체를 붙여넣기 (기존 프로젝트와 함수 이름이 겹침)
2. `전체DB` 시트 맨 오른쪽(S열 등)에 **`전시중`** 열 추가 — 현재 전시 중인 작품 행에 전시명(예: `혼자였던 적 없는 꿈 展`) 입력, 아니면 비워두기
   - `현재전시정보`, `전시이력` 시트는 처음 저장할 때 Apps Script가 자동으로 만듭니다. 미리 만들어둘 필요 없습니다.
3. **관리자 비밀번호 설정**: Apps Script 편집기 좌측 톱니바퀴(프로젝트 설정) → **스크립트 속성** → 속성 추가 → 키 `ADMIN_PASS`, 값은 원하는 비밀번호. **설정하지 않으면 관리자 기능(방명록 숨김/삭제, 전시 설정, 지난 전시 등록)은 전부 거부됩니다.**
4. 배포 > 새 배포 > 웹 앱 (실행: 나 / 액세스: 모든 사용자) → `/exec` 주소 복사
5. `docs/assets/config.js` 의 `API_URL` 에 붙여넣고 커밋
   - 작가 연락처, 대화청년 이름/연락처 열은 코드에서 읽지 않으므로 외부에 노출되지 않습니다.
   - 코드 수정 후에는 '배포 관리 > 새 버전'으로 재배포해야 반영됩니다.

## 2. 작품 이미지
시트의 드라이브 이미지 파일은 **'링크가 있는 모든 사용자 – 뷰어'** 로 공유되어 있어야 페이지에 보입니다.

## 3. GitHub Pages 배포
1. 이 브랜치를 `main` 에 병합
2. 저장소 Settings > Pages > Source: `Deploy from a branch` / Branch: `main` / Folder: `/docs`
3. 주소: `https://<계정>.github.io/oneul-art-galler/`

## 4. 전시 바꾸기 (관리자 페이지 또는 시트, 둘 다 가능)
- **관리자 페이지(`admin.html`)에서**: '현재 전시 설정' 탭에서 전시명·기간·장소·안내 링크를 저장하고, 전시중인 작품을 체크해 저장하면 끝입니다.
- **시트에서 직접**: `현재전시정보` 시트 1행(전시명/기간/장소/링크)을 수정하고, `전체DB`의 `전시중` 열에 전시명을 입력/삭제하면 됩니다.
- 전시가 끝나면 '지난 전시 아카이브'(관리자 페이지 또는 `전시이력` 시트)에 한 줄 추가해 두면 `now.html`의 '지난' 탭에 쌓입니다.
- 방명록 글을 숨기려면 관리자 페이지에서 '숨기기'를 누르거나, '방명록' 시트 D열에 `Y`를 입력하세요.

## 5. 관리자 페이지 주의사항
- `admin.html`은 공개 nav/footer 어디에도 링크되어 있지 않습니다. 운영진끼리만 주소와 비밀번호를 공유하세요.
- 비밀번호는 브라우저에 임시 저장(세션 단위)되며, 모든 저장/삭제 요청마다 Apps Script가 서버에서 다시 검증합니다.
- 방명록 "삭제"와 "지난 전시 삭제"는 시트에서 행을 완전히 제거하며 되돌릴 수 없습니다. "숨기기"는 공개 목록에서만 빠지고 시트에는 남습니다.
- 간단한 공유 비밀번호 방식이라 민감한 개인정보 관리에는 적합하지 않습니다 — 이미 공개해도 괜찮은 정보(전시 정보, 방명록 공개 여부)만 다룹니다.

## 6. 청년작가 지원사업 소개 페이지
`program.html`은 현재 임시 구성입니다. 실제 모집 일정·지원 자격·신청 방법 등 원고가 준비되면 해당 섹션의 "원고 반영 예정" 표시가 있는 부분을 교체해 주세요.
