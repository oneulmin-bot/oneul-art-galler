## 0. 시트 구조 (중요)
사이트는 하나의 구글시트(스프레드시트) 안의 여러 탭을 사용합니다.
| 시트 탭 | 용도 | 비고 |
|---|---|---|
| `작품리스트` | 작품 원본 데이터 | 기존 운영 시트. 헤더: 작품번호/제작년도/선정 프로젝트/작가명/작가 연락처/작품명/작품크기/재료/작품소개/작가소개/대화청년(주제)/작품이미지/음성해설. **P열(16번째 열)**에 `반환` 또는 `폐기`라고 적으면 그 작품은 사이트에서 "이제 더 이상 (사)오늘은이 소장하지 않는 작품이에요"로 표시되고, 홈의 소장 작품 수·미리보기·캐러셀에서는 제외됩니다(전체 작품 목록에서는 계속 보이되 "소장 종료" 표시가 붙음) |
| `전시리스트DB` | 어떤 작품이 어떤 전시에 들어갔는지 기록 | 기존 운영 시트, **읽기 전용으로만 사용**(수식 걸린 자동열 보존). 전시 1개당 참여 작품 수만큼 행이 반복됨: 전시명/전시기간/전시장소/작품번호/작가명(자동)/작품명(자동)/메모 |
| `전시설정` | 전시별 포스터·서문 | **자동 생성**. 전시 1개당 1행: 전시명/포스터URL/서문 |
| `현재전시` | 지금 "현재 전시"로 보여줄 전시명 1개 | **자동 생성**. 관리자 페이지에서 지정 |
| `방명록` | 방명록 글 | 기존과 동일 |

새 전시를 올릴 때는 **운영진이 `전시리스트DB`에 먼저 작품을 등록**해야 관리자 페이지 드롭다운과 사이트에 나타납니다. 포스터/서문/“현재 전시” 지정은 관리자 페이지에서 합니다.

## 1. Apps Script 연결
1. script.google.com 에서 **새 프로젝트**를 만들어 `apps-script/Code.gs` 전체를 붙여넣기 (기존 프로젝트와 함수 이름이 겹침)
2. **관리자 비밀번호 설정**: Apps Script 편집기 좌측 톱니바퀴(프로젝트 설정) → **스크립트 속성** → 속성 추가 → 키 `ADMIN_PASS`, 값은 원하는 비밀번호. **설정하지 않으면 관리자 기능(방명록 숨김/삭제, 전시 설정)은 전부 거부됩니다.**
3. 배포 > 새 배포 > 웹 앱 (실행: 나 / 액세스: 모든 사용자) → `/exec` 주소 복사
   - 전시 포스터 업로드 기능이 구글 드라이브에 파일을 만들기 때문에, 배포 승인 화면에서 **드라이브 접근 권한도 함께 승인**해 달라는 안내가 나올 수 있습니다. 승인해주세요.
4. `docs/assets/config.js` 의 `API_URL` 에 붙여넣고 커밋
   - 작가 연락처, 대화청년 이름/연락처 열은 코드에서 읽지 않으므로 외부에 노출되지 않습니다.
   - 코드 수정 후에는 '배포 관리 > 새 버전'으로 재배포해야 반영됩니다.

## 2. 작품 이미지
시트의 드라이브 이미지 파일은 **'링크가 있는 모든 사용자 – 뷰어'** 로 공유되어 있어야 페이지에 보입니다.

## 3. GitHub Pages 배포
1. 이 브랜치를 `main` 에 병합
2. 저장소 Settings > Pages > Source: `Deploy from a branch` / Branch: `main` / Folder: `/docs`
3. 주소: `https://<계정>.github.io/oneul-art-galler/`

## 4. 전시 바꾸기
1. (처음 한 번) 운영진이 `전시리스트DB` 시트에 해당 전시의 작품들을 등록(전시명/전시기간/전시장소/작품번호)
2. 관리자 페이지(`admin.html`) → **전시 관리** 탭 → 상단 드롭다운에서 그 전시를 선택
3. 포스터 이미지를 올리고 서문을 적어 **"포스터·서문 저장"**
4. **"이 전시를 현재 전시로 지정"** 클릭 — 홈/전시 페이지의 '현재' 탭에 바로 반영됩니다
5. 전시가 끝나면 다음 전시를 올리고 다시 "현재 전시로 지정"만 눌러주면, 이전 전시는 자동으로 '지난' 탭 아카이브로 넘어갑니다(별도로 삭제/이동할 필요 없음)
6. 방명록 글을 숨기려면 관리자 페이지에서 '숨기기'를 누르거나, '방명록' 시트 D열에 `Y`를 입력하세요.

## 5. 관리자 페이지 주의사항
- `admin.html`은 상단 메뉴에는 없고 푸터에만 작은 글자로 링크되어 있습니다. 운영진끼리만 비밀번호를 공유하세요.
- 비밀번호는 브라우저에 임시 저장(세션 단위)되며, 모든 저장/삭제 요청마다 Apps Script가 서버에서 다시 검증합니다.
- 방명록 "삭제"는 시트에서 행을 완전히 제거하며 되돌릴 수 없습니다. "숨기기"는 공개 목록에서만 빠지고 시트에는 남습니다.
- 전시 포스터는 업로드한 이미지 파일이 구글 드라이브에 저장되고 "링크가 있는 모든 사용자 – 뷰어"로 자동 공유됩니다.
- 간단한 공유 비밀번호 방식이라 민감한 개인정보 관리에는 적합하지 않습니다 — 이미 공개해도 괜찮은 정보(전시 정보, 방명록 공개 여부)만 다룹니다.

## 6. 음성해설 (시각장애인 안내 영상)
- `작품리스트` 시트의 `음성해설` 열에 유튜브 링크(`youtu.be/...`, `youtube.com/watch?v=...` 등)를 넣으면 작품 상세 팝업에 영상이 자동으로 임베드되고, "시각장애인분들을 위한 음성해설 안내 영상입니다"라는 안내 문구가 함께 표시됩니다.
- 유튜브 링크가 아닌 다른 오디오 링크를 넣으면 기존처럼 "🎧 음성해설 듣기" 버튼(새 탭 열기)으로 표시됩니다.
- 음성해설이 있는 작품은 썸네일 오른쪽 위에 🎧 표시가 붙습니다.

## 7. 소식 페이지 (보도자료 · 블로그 · 홈페이지 글)
`news.html`은 아직 구조만 있는 상태입니다. `docs/assets/news-data.js` 파일을 열어 배열에 `{ title, source, date, url }` 형식으로 한 줄씩 추가하면 바로 목록에 나타납니다(최신 날짜가 위로 자동 정렬). 별도 시트 연동은 하지 않았습니다 — 필요해지면 구글시트로 옮기는 것도 가능합니다.

## 8. 청년작가 지원사업 소개 페이지
`program.html`은 현재 임시 구성입니다. 실제 모집 일정·지원 자격·신청 방법 등 원고가 준비되면 해당 섹션의 "원고 반영 예정" 표시가 있는 부분을 교체해 주세요.
